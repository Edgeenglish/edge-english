재등록 · 보강 이월 · 적립금 넣기/빼기 — 운영자 화면 시안

11/8 DB 함수 3개(admin_register_renewal · admin_carry_over_makeups · admin_reward_adjust)에 운영자 버튼을 붙이는 시안입니다. 버튼은 모두 학생 상세 화면 안에 둡니다. 학생·금액·날짜는 전부 예시이고, 실제 값과 정책 숫자는 바꾸지 않았습니다. 버튼·칩은 눌러 볼 수 있습니다.

PC
휴대폰

반영한 결정 (11/8 검토)

  1. 시작일: 지난 종료일 뒤 첫 정규 수업일을 자동으로 넣고, 필요하면 수정 (예시: 종료 11/18(수) → 11/20(금), 정규 수·금 KST)
  2. 수강 상품: 지난 수강권과 같은 기간·주 횟수·길이를 미리 골라 둠
  3. 금액: 직접 입력, 지난 결제 금액은 참고로만 표시
  4. 입금·결제 시각: 기본값 없음. 실제 확인한 시각을 넣어야 저장됨
  5. 적립금 사유: 직접 입력 (빠른 문구 버튼 없음)
  6. 대시보드 ‘수강기간 종료 임박’ 카드에 [재등록 넣기] 추가
  7. 창 안 설명·경고 문구를 줄임 (막히는 이유만 버튼·입력칸 바로 아래에)

개발 메모 (시안 승인 뒤)

  • 보강 이월 화면에는 ‘이월할 수 있는 보강 목록’을 읽는 함수가 하나 더 필요합니다 (지금 함수는 넣기만 함). 읽기 전용이라 기존 데이터는 안 바뀝니다.
  • 적립금 잔액·내역을 운영자 학생 상세에 보여 주려면 읽기 함수에 적립금 내역을 추가해야 합니다 (학생 화면은 이미 표시 중).
  • 세 창 모두 같은 요청 번호로 두 번 눌러도 한 번만 저장됩니다 (DB 함수가 이미 처리). 휴대폰 입력 중 창이 닫혀도 입력을 되살리는 기존 방식(프로필 수정 창)을 그대로 씁니다.
  • 개발·검증은 시험 DB·lms-test에서만, 운영 반영은 대표 승인 뒤.
