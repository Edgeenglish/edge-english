## 2. 안내서 원문 (이미지에서 옮김)

**1장 — 엣지영어 수업안내 · 수업 전 꼭 확인해주세요 :)**
1. 수업 취소/변경은 수업 시작 6시간 전까지 가능해요. 6시간 이내에 취소/변경 신청 시에는 수업 1회가 자동 차감됩니다.
2. 회원님의 인터넷 문제, 기기 오류, 개인 사정 등으로 인해 수업에 불참하신 경우에도 예외 없이 수업 1회가 차감되므로, 수업 전에 환경 점검 꼭 부탁드려요. (LTE ❌ WIFI ⭕)
   수업 진행이 어려울 것 같다면, 수업 시작 6시간 전까지 엣지영어 카카오톡 채널로 꼭 연락 주세요!
3. 등록한 수업은 등록하신 수강 기간(4주~12주) 내에 모두 사용해주셔야 해요. 수강 기간이 지나면 남은 수업은 자동 소멸되며, 별도 연장은 어렵습니다. 단, \*수강 기간 종료 당일까지\* 재등록하시면 남은 수업은 모두 다음 수강 기간으로 이월 가능합니다.
4. 취소/변경 가능 횟수는 4주 기준 아래와 같습니다. 주 1회 수업: 1회 / 주 2회 수업: 2회 / 주 3회 이상 수업: 3회. \*취소/변경 가능 횟수는 4주마다 갱신됩니다\*
5. 보강 수업은 정상 취소/변경(수업 시작 \*6시간 이전\*) 경우에만 제공되며, 반드시 현재 \*수강 기간 내에만\* 진행됩니다. 꼭 수강 기간 내에 보강 신청을 해주세요. 보강은 기본적으로 기존 강사와 진행되지만, 스케줄에 따라 다른 강사님이 대신 수업하실 수 있어요.
6. 엣지영어는 공휴일에도 정상 수업이 진행됩니다. 공휴일에 쉬고 싶으실 경우, 꼭 수업 시간 6시간 이전까지 엣지팀으로 신청해주세요 🙂 공휴일 취소는 취소/변경 가능 횟수에서 차감되지 않습니다.
7. 강사님이 예정된 시간보다 5분 이상 수업에 오지 않는 경우, 엣지영어 카카오톡으로 바로 연락을 주세요. 엣지팀이 최대한 빠르게 확인 후 안내 드리겠습니다.

**2장**
8. 수업에 늦으실 경우, 엣지영어 채널 또는 강사님께 이메일로 미리 알려주세요. 다만, 수업 종료 시간은 연장되지 않습니다.
9. 고정 수업 일정은 월 1회 변경 가능합니다. 일정 변경은 다음 주부터 적용됩니다. (당일 즉시 변경 🙅) 변경된 시간이 새로운 고정 수업 시간이 됩니다.
10. 강사 변경이나 교재 변경은 횟수 제한 없이 언제든지 요청하실 수 있습니다. '이 강사님과 더 잘 맞을 것 같아요', '교재를 바꿔보고 싶어요'처럼 작은 의견도 언제든 환영합니다 🙇 부담 갖지 말고 편하게 말씀해 주세요! 엣지팀이 친절한 상담 후 변경 도와드리겠습니다.
11. 수업 시간은 모두 한국 시간(KST) 기준으로 안내됩니다.

이미지로 직접 읽어 OCR에서 깨졌던 두 곳을 확인함: "(LTE ❌ WIFI ⭕)" = 와이파이 권장, "(당일 즉시 변경 🙅)" = **당일 즉시 변경은 안 됨**. 다만 '불가'라는 뜻이 이모지(🙅)로만 표현돼 있어, 화면 낭독기·텍스트 변환·번역에서는 뜻이 사라짐 → 텍스트판에서는 "당일 즉시 변경은 안 됩니다"처럼 글로 적어야 함.
