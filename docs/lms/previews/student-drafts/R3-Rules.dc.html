'할 일' 알림 (메인 맨 위 한 줄)
학생이 직접 처리해야 할 때만 보이고, 처리하면 사라져요. 2개 이상이면 "할 일 2" → 누르면 목록.
보이는 경우
· 새 수업 안내 확인·동의가 필요할 때
· 그 밖에 학생 응답이 필요한 일 (규칙이 정해지면 추가)
보이지 않는 경우
· 강사 확인 중 · 운영자 확인 중 (학생이 기다리기만 하면 됨)
· 재등록 (아래 전용 카드가 따로 있어 중복하지 않음)
· 강사 미입장 신고 (수업 칸에 따로 나타남)
재등록 카드
기준: 아직 하지 않은 정규 수업 수 (날짜·D-day가 아니라 횟수)

누르면 열리는 곳
· 신청 진행 상태 한 줄 → 신청 상세 (내가 고른 후보 날짜·진행 단계)
· 결제 내역 → 지금·지난 수강권과 결제 확인 + 아임웹 영수증 링크
· 적립금 내역 → 잔액과 지급·사용·복구 이력
