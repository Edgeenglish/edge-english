# 01. 현재 상태 분석 (2026-10-16 직접 확인)

기획서에 적혀 있다는 이유로 구현됐다고 보지 않고, 실제 파일·시트를 열어 본 결과만 적었다.
개인정보는 구조(머리글·형식)만 확인했고 이 문서에 옮기지 않았다.

## Google 시트 구조

### Master Sheet (`시트1` 외 4개 탭)

- 학생 3명(STU-0001~0003)만 들어 있음. 자기소개 문구가 같은 등 **시험용 데이터로 보임**. 실제 학생 수강현황 시트는 STU-0013까지 있으므로 실제 운영은 아직 강사별 Class Record + 학생별 시트 중심으로 판단됨.
- 학생 1명 = 1행, 35칸. 핵심: `Student ID`, 이름(한·영), 거주국가, 담당강사, 등록수업수(수식), 수업요일(`화,목`), 수업 시작시간, 길이, 교재, 수강기간 시작일, 적립금, 상태, 학생 시트 주소, 등록기간(주), 1·2·3차 시작·종료일(수식), 최종 종료일, 이월 수업 수, 학생 시간대(IANA, 드롭다운 16개).
- 기간 수식: `1차 종료 = 시작 + 27`, `2차 시작 = 1차 종료 + 1` … → 기획서 규칙과 일치.
- **문제 발견**
  1. **24주(6기간) 미지원**: 1·2·3차까지만 칸이 있고 `최종 종료일 = IF(주>=12, 3차 종료…)` → 24주 학생은 종료일이 12주 기준으로 계산됨.
  2. **표시용 이름(운영진용)에 시각이 숫자로 섞임**: `… - 화,목 0.708333` (오후 5시가 소수로 표시). 변경신청트래커 선택 목록에 그대로 보임.
  3. 수강 이력(1차·2차 등록)과 기간(1·2·3차)이 한 행에 섞여 있어 재등록할 때마다 칸을 덮어써야 함 → 이력 보존 불가.
- `강사정보` 탭: 이름·한글소리·국가·Meet 링크·캘린더 링크·Class Record 주소·IANA 시간대.
- `변경신청트래커`: 신청일시·학생·수업 날짜·시간·내용·기간 내 여부·6시간 전 여부·남는 변경권·최종 판정. (값은 입력값으로 저장됨 → 계산 주체는 붙어 있는 스크립트로 추정, 확인 불가)
- `상태매핑표`: 14개 상태 × 학생용 문구·페이 대상·인센티브·수강권 차감·변경권 차감.
- `적립금이력`: 학생·지급일·금액·사유·유효기간·사용여부.

### 강사 Class Record (두 가지 형식이 섞여 있음)

| | 기존 형식 (Benny, Olivia 등 실제 운영) | 새 템플릿 (Cindy, 시험용) |
|---|---|---|
| 학생 연결 | 학생 **이름**으로 연결 | Student ID 자동 조회 (Master Sheet IMPORTRANGE) |
| 시간 | Local + KST 두 벌 | KST |
| 시간대 | `Teacher Info`에 **고정 시차(예: +2)** → 서머타임 때 틀어짐. 서머타임용 탭을 따로 복사해 씀 | IANA 시간대 |
| 상태값 | 14개 드롭다운 | 상태매핑표 연결 |
| 기록 시각 | **칸 없음** | 칸 없음 |

- **기록 시각 칸이 없어 '수업 후 10분 안 기록'(인센티브 1번, +$1.50)을 시트로는 객관적으로 잴 수 없음** → LMS에서 서버 시각으로 자동 기록하면 해결.
- Class Type 선택지에 `free trial`, `Carryover to next/from previous period`, `compensation` 이 있음. 체험수업은 운영하지 않는다는 FAQ와 다름(과거 값으로 보임).
- 강사 안내문: 진행되지 않은 수업까지 모두 기록하도록 요구 → 시스템이 이미 아는 취소는 LMS가 자동 기록하고, 강사는 실제 진행 대상 수업만 기록하면 되도록 줄일 수 있음.

### 학생 수강현황 시트

- 학생마다 파일 1개(모바일 탭·PC 탭·핵심영어 탭). Drive에 다수 존재.
- Master Sheet 상태매핑표를 IMPORTRANGE로 가져오는 칸이 `#REF!` (연결 승인 안 됨) → 파일별 연결이 깨지기 쉬운 구조.
- 링크 공유 방식이라 링크가 새면 정보가 노출됨 (기획서 11-3 지적과 같음).

### 신청서 (구글폼 응답 시트)

- 항목: 이름·연령대·알게 된 경로·영어 고민·휴대폰·수업 길이·횟수·희망 시간(자유 서술)·이메일·시작 희망일·영문 이름·성별·거주 국가/도시·수강 기간·입금자명.
- 폼 안내: "신청서 제출 후 카카오톡 채널로 메시지를 보내야 신청 완료".
- 희망 시간이 자유 서술이라 자동 배정에는 쓸 수 없음 → 운영자가 보고 고르는 현재 방식 유지가 맞음.

### 강사 정산

- `수업 페이 계산` 시트에 월별 탭. 시급 17.00 → 20분 5.66 / 40분 11.33 / 50분 14.16 (**센트 이하 버림**), 15.00 기준표도 있음, 25분 단가 칸도 있음.

### Google Calendar

- Master Sheet에 강사별 보조 캘린더 링크가 있음(엣지영어 계정 소유 그룹 캘린더). 기획서 기준: 운영자가 직접 넣고, 강사는 폰 앱으로 봄.
- 자동 연동 스크립트가 있는지는 **확인하지 못함**.
