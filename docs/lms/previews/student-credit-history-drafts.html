A안·B안 비교

A안 · 처리 내역으로 이동

  • 새 창 없음, 처리 내역에 칩 하나만 추가
  • 홈을 떠나 다른 탭으로 감 (휴대폰에서 뒤로 가기 필요)
  • 여러 기간 취소가 섞여 보여 '총 2개 중 0개'와 줄 수가 바로 안 맞음
권장

B안 · 홈에서 창

  • 홈에 머문 채 '왜 0개지?'가 바로 풀림
  • 지금 기간만 보여 카드 숫자와 줄이 그대로 맞음
  • ①의 처리 내역 줄은 그대로 쓰고, 같은 자료를 기간별로 묶어 보여 줌 (추가 화면 1개)

개발 범위(두 안 공통): 처리 내역 DB 함수에 수업 취소마다 '쓴 변경권·그 뒤 남은 수·일찍/늦은/공휴일' 칸을 더하는 migration 1개(읽기만, 데이터 변경 없음). 학생 화면·운영자 보기는 같은 함수를 씁니다.

정해 주실 것 (번호로 답)
  1. ②는 B안(권장) / A안
  2. B안이면 늦은 취소(변경권 안 씀)도 창에 보이기(권장: 보임, '사용 안 함 · 수업 1회 차감') / 변경권 쓴 줄만

예: '1 B 2 보임'
