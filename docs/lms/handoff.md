(2026-10-21 대표 확인 — H22와 같음: 강사는 '그 일정 가능'까지만 답했고, 운영자가 강사에게 '그럼 수업 확정!'을 보내야 수업이 성립하는데 학생에게만 확정을 보내고 강사에게는 안 보냄 → 학생만 기다림. 원인은 강사가 아니라 **양쪽 최종 확정 안내 중 한쪽 누락**) ② 실제 학생·강사·고정 수업 데이터 넣기(운영 DB 전환 포함, 승인 필요) ③ D-50 후보 계산(강사 휴무 포함) ④ D-42 신청서 가져오기
