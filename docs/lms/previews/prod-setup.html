운영 DB 만들기 · edgeenglish-lms

번호 순서대로. 약 20분, PC 권장. 1번만 시험용(edgeenglish-lms-test)에서, 나머지는 새 운영 프로젝트에서 해요.

요금제는 Free로 시작해요. 시트 대신 LMS에만 기록하는 날 Pro로 바꿔요 (Claude가 먼저 알려 드려요). 운영 DB에는 가상 데이터를 넣지 않고, 실제 학생 입력·홈페이지 연결은 다음 단계예요.

1먼저 시험용 DB에 복구 안전장치

붙여 넣는 곳: 프로젝트 edgeenglish-lms-test → SQL Editor → New query → Run.
정상: edgeenglish-lms-test · 6 한 줄. 기존 데이터는 그대로예요. 문제 없으면 바로 2번으로

2프로젝트 만들기

  1. 왼쪽 위 조직 메뉴 → New organization → 이름 EdgeEnglish LMS → 요금제 Free (대표 결정 A40). 시험용 조직은 그대로 둠
  2. 방금 만든 EdgeEnglish LMS 조직 안에서 다음 단계 진행
  3. New project → 이름 edgeenglish-lms · 지역 Northeast Asia (Seoul)
  4. Database password → Generate → 비밀번호 관리 앱에만 저장 (Claude에게 보내지 않음)
  5. Data API는 켜 둔 채로 Create → 2~3분 기다림
여기부터 SQL은: 새 프로젝트 edgeenglish-lms → 왼쪽 SQL Editor → New query → 붙여 넣기 → Run. 단계마다 새 query 하나씩. 화면 위쪽 프로젝트 이름이 edgeenglish-lms 인지 꼭 확인

5확인 (읽기만)

정상: 8줄 모두 통과

6로그인 설정 (화면)

시험용 프로젝트와 똑같이

  1. Authentication → Sign In / Providers → Allow new users to sign up: 끄기
  2. Email: Confirm email 켬 · Email OTP Length 6 · OTP Expiration 600
  3. Multi-Factor: TOTP 켜짐 확인
  4. Resend → API Keys → 새 키 supabase-prod (Sending access · edgeenglish.kr) → Supabase Authentication → Emails → SMTP Settings: Host smtp.resend.com · Port 465 · Username resend · Password = 그 키 · Sender support@edgeenglish.kr · 이름 엣지영어
  5. Emails → Templates → Magic Link: 시험용 프로젝트의 제목·본문을 그대로 복사해 붙여 넣기

7대표 계정 만들기 (화면)

  1. Authentication → Users → Add user → Create new user
  2. 이메일 support@edgeenglish.kr · 비밀번호는 아무 긴 값 (쓰지 않음) · Auto Confirm User 체크
  3. Send invitation은 쓰지 않음 (가입을 끄면 초대 계정은 로그인이 안 됨)

8대표 계정을 운영자(대표)로 연결

정상: support@edgeenglish.kr · admin · owner 한 줄 (0줄이면 7번을 먼저)

9Claude에게 알려 주기

  1. 왼쪽 Database → Backups 화면 캡처 (요금제별 자동 백업이 실제로 어떻게 보이는지 확인용)
  2. Project Settings → Data API → Project URL 의 xxxx.supabase.co 부분 (비밀 아님)
  3. Secret key·DB 비밀번호는 보내지 않음

오류가 나면 오류 첫 줄만 Claude에게 보내 주세요. 1·4번은 한 묶음이라 오류가 나면 아무것도 바뀌지 않아요.

운영 DB를 바꾸기 직전 — 매번 백업

무료 요금제 동안 매주 1회 + DB를 바꾸기 직전에 받아요. 읽기만 하는 SQL이라 데이터를 바꾸지 않아요.

B직접 백업 받기

  1. [복사] → edgeenglish-lms SQL Editor → New query → 붙여 넣기 → Run
  2. 결과 표 오른쪽 위 Export → Download CSV
