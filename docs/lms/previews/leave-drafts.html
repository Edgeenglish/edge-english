정할 것 2가지

Q1. 처리 단위 A. 학생별로 한 번에 고르고, 필요하면 일부 날짜만 다르게 B. 처음부터 수업마다 하나씩 고르기 추천 A — 대부분 휴무 기간 전체를 같은 방식으로 처리해서 누를 게 적어요.
Q2. 대체강사 수업 확정 시점 A. 대체강사 가능 → 학생 안내 → 학생 OK 받은 뒤 확정 (정책 원본 A41 그대로) B. 대체강사 가능 → 학생에게 안내 보내면 바로 확정, 싫다고 하면 되돌림 (A41 문구 변경 필요) 추천 A — 학생이 안내를 못 본 채 모르는 강사 수업이 열리는 일을 막아요. B는 1번 덜 누르는 대신 그 위험이 있어요.

이미 정하신 대로 들어가는 것

  • 1순위 대체강사(원래 시간) · 2순위 강사 기다림 보강, 학생 선택지는 이 둘뿐 (A41)
  • 연장은 보강이 종료일 뒤로 확정될 때 마지막 보강일까지만 자동, 연장된 날엔 정규 수업 안 만듦 (A20)
  • 휴가 보강은 날짜 미정인 채 종료일이 지나도 권리 유지
  • 보강·안내·[보냈어요]는 이미 만든 취소·보강 처리를 그대로 씀
  • 이미 입력한 학생의 휴가 보강(Olivia 11/2~11/10)은 ②에 '기다림'으로 보이고 대체강사로 바꿀 수 있음

이번에 안 만드는 것

  • 학생·강사가 직접 고르는 화면 (강사 LMS·학생 LMS 단계)
  • 자동 메시지 발송 (지금처럼 복사 → 보냄)
  • 대체강사 자동 추천 순위 (비어 있는 강사만 보여 줌)
