**이미 확정된 결정이므로 다시 묻지 않는다.** 새 정책 판단이 필요한 것만 따로 보고한다.
시험용 환경에서 먼저 구현·검증, 운영 DB·운영 배포는 별도 승인.

## ① 정규 수업 일정 수정 — A안
- 운영진이 기존 학생의 정규 **요일·시작 시간만** 변경. 주간 횟수·수업 길이·담당 강사는 이 화면에서 변경 안 함
- 적용 시작일 선택 → 바뀔 수업 전체 미리 보기
- 검사: 강사 가능 시간·기존 수업·보강·대체수업·수업 간 휴식 10분. 저장 시 DB에서 다시 검사
- 지난 수업, 이미 확정된 보강·대체수업은 변경 안 함
- 변경 전후 기록·수정 사유 보존

## ② 학생 사정으로 정규 일정 변경 시 종료일 — C안
- 종료일 연장 안 함. 남은 정규 수업 전체가 기존 최종 종료일 안에 들어가야 함, 하나라도 넘으면 저장 차단
- 넘친 수업을 날짜 미정 보강으로 자동 전환하지 않음. 수업 횟수·변경권 정책 그대로
- 다른 요일·시간을 고르도록 구체적인 오류 안내
- 강사 휴무로 인한 연장은 기존 정책 유지
- **꼭 시험**: 마지막 수업만 종료일 넘김 / 날짜·요일 변경으로 횟수 부족 / 확정된 보강과 충돌

## ③ 일정 변경 후 안내 — A안
- 저장 즉시 학생 LMS·강사 LMS·운영진 일정에 반영
- 변경된 전체 일정 + 정확한 시간대를 넣은 **학생용 카카오톡·강사용 WhatsApp 문구 자동 생성** → 운영진 복사·직접 발송
- 각각 [발송 완료] → 발송 이력 기록, 학생·강사 안내 상태 따로 관리
- 자동 이메일은 이번 범위 아님

## ④ 이름 기준
- `name_ko` 한국 이름(운영진 식별) · `name_en` 여권 영문 이름(강사 공식 식별) · `display_name` Preferred Name(선택)
- 운영진 LMS `김서연 (Kim Seoyeon)` · 강사 LMS `Kim Seoyeon (Sarah)` · 학생 LMS `김서연`
- 강사·운영진이 학생을 언급하는 안내 문구: 영문 이름 + 한국 이름 함께
- Preferred Name 없으면 괄호 없이 영문 이름만. English Name 칸 따로 만들지 않음

## ⑤ Google Sheets Student Info 이전 — B안
- 강사별 시트 Student Info를 읽어 학생별로 **시트 값 ↔ LMS 값 나란히** 표시, 대표가 학생별로 확인·승인한 것만 반영
- 기존 LMS 데이터 무조건 덮어쓰기 금지, 시트는 읽기 전용(절대 수정 금지)
- 대조: 이름·Preferred Name·거주지·성별/연령대·이메일·Google Docs 링크·기존 자기소개 등
- 기존 자기소개는 원문 그대로 보관, 7항목으로 나누지 않음
- A2/B1 같은 기존 레벨은 4단계로 자동 변환 안 함, 필요하면 참고 정보로 유지
- 신규 학생은 시트 안 만들고 LMS로만

## ⑥ 대체강사 학생 정보 접근
- **열람만**: 영문 이름·Preferred Name, 수업에 필요한 프로필·자기소개·선호도, 영어 레벨·교재·수업 방식·교정 선호, Class Notes(Docs) 링크, 최근 Covered Topics 3건, 해당 대체수업 일정·수업 정보
- **비공개**: 학생 이메일·결제 정보·운영 메모
- Recent Covered Topics: Covered Topics가 기록된 최신 3건(날짜·담당 강사·내용), 정규·대체 강사 기록 모두 포함, 1~2건이면 있는 만큼, 없으면 `No previous class records`
- 접근 기간: **대체수업 확정 시점부터 그 수업 종료 24시간 후까지**(대표가 정한 값). 지나면 자동 차단, 여러 대체수업이면 각각 반영, 대체수업 취소되면 그 수업에 따른 권한 종료. **기존 '지난 60일' 규칙을 이 기준으로 교체**
- 대체강사는 프로필·레벨·선호 수정 불가. 본인이 진행한 수업의 Class Record 작성·확인·수정은 유지
- 화면 숨김이 아니라 **DB 권한 검사**로 차단. 정규 담당 강사의 기존 권한은 유지

## ⑦ 검증 — 강화된 B안
- 시험용 DB에만 전용 운영자·강사·학생 계정. 운영 실제 학생 정보 복사 금지, 인증·권한 보안 약화 금지, 실사용 계정 인증번호 요구 금지
- 필수: ① PC·모바일 모든 신규 화면 열기·수정·저장·취소·닫기·뒤로가기 ② 운영진 변경이 학생·강사 화면에 정확히 반영 ③ 시간대 전환·서머타임·날짜·요일 변경 ④ 일정 충돌·강사 휴무·변경권 부족·종료일 초과·중복 보강 ⑤ 정규 일정 수정 때 남은 회차·종료일·이월 보존 ⑥ 대체강사 접근 기간·권한 제한 ⑦ 기존 기능 회귀 ⑧ UI 배치·불필요한 클릭·흐름 끊김·헷갈리는 표현까지 직접 보고 고침
- 자동 테스트 통과만으로 완료 처리 금지. 실제 브라우저 PC·모바일 클릭 검증, 못 본 항목은 명확히 남김. 이후 ChatGPT Work가 따로 최종 검증

## 공통 — 시간대 표시 (CLAUDE.md '시간 표기')
- 기준 시간대가 없는 시각은 LMS 어디에도 없게
- 학생 화면 = 학생 도시 시간 + KST, 강사 화면 = 강사 도시 시간 + KST, 운영진 화면 = KST 명확히 + 필요하면 학생·강사 현지 시간
- 해외 사용자는 KST 동시 표시 끄기 가능, 꺼도 도시명·시간대는 유지. 서머타임·날짜·요일은 실제 수업 날짜 기준
- 일정표·수업 상세·보강 신청·변경 확인·Class Record·학생 프로필·안내 문구 등 모든 화면
- 보강 고르기 [나중에 고르기](창만 닫고 보강 권리 유지) 유지
