# 13. 환불 기준 최종안 (제안 · 대표 승인 전) — 2026-10-17

근거: 정책 원본 **A35**(환불 공제 3원칙, 대표확정)·H14·H15·H17, 기준표 POL-PAY-04, 충돌 CF-09.
상태: **제안.** 사이트 FAQ·계약서·아임웹 안내·LMS DB/계산 로직은 **아직 바꾸지 않았다.** 대표 승인 후 반영한다.
이 문서는 공개 자료 조사이며 **법률 자문이 아니다.** '법률 확인 필요'로 표시한 항목은 전문가(변호사·한국소비자원 상담 등) 확인 후 확정한다.

## 0. 확정된 것과 아직 정할 것

| 구분 | 내용 | 상태 |
|---|---|---|
| 사은품 공제 | 품목·개별 가격(근거)·중도해지 시 공제 조건을 **계약 전 고지·동의 보관**, 법령상 허용될 때만 공제. 학생별 제공 내역 기록 | ✅ 방향 확정 (A35-1) |
| 카드 수수료 | 학생 환불금에서 **공제하지 않음** | ✅ 확정 (A35-2) |
| 중도해지 위약금 | 적용 법령의 허용 기준·상한 안에서만. 일률 10% 자동 적용 아님. 청약철회·사업자 귀책 등 예외 반영 | ✅ 방향 확정 (A35-3) |
| 적용 대상 | 새 계약부터. 지금까지 6개월(24주) 등록 학생 없음 → 사은품 고지는 새 24주 계약부터 | ✅ 확정 |
| 환불 총 산식·위약금 비율·예외·법률 분류·실제 문구 | 아래 제안 | ⬜ 대표 승인 전 |

## 1. 적용 법령 (사실 확인 결과)

- 교육청 학원(원격교습) 등록 없음, 성인 취미 대상(대표 확인, H15) → **학원법 별표 4는 직접 적용되지 않는 것으로 본다**(등록 의무 여부는 교육청 안내 기록 보관 권장).
- 적용 후보:
  1. **전자상거래법** — 온라인 판매(아임웹·계좌이체 안내)의 청약철회.
  2. **방문판매법 계속거래(제31·32조)** — 1개월 이상 계속 제공 + 중도 해지 시 환급 제한·위약금 약정이 있는 거래. 학생은 **기간 중 언제든 해지 가능**, 사업자는 손실을 현저히 넘는 위약금 청구 불가. 고시를 넘는 위약금 약정은 무효, 학생에게 더 유리한 약정은 유효.
  3. **공정위 고시 제2019-9호**(계속거래 위약금·환급 산정기준, 2019-11-19 시행) — 보도자료 기준 적용 업종 5개(결혼중개·**컴퓨터통신교육**·헬스·미용·학습지). **컴퓨터통신교육업: 계약일 또는 서비스 이용 가능일부터 7일 이내 위약금 불가, 그 외 총계약대금의 10% 상한.** 환급 = 낸 대금 − 이미 제공받은 부분 − 위약금 − 부가상품 가액. 부가상품을 돌려주면 그 가치만큼 환급금을 늘리거나 위약금을 줄여야 함.
- **법률 확인 필요 ①**: 1:1 **실시간** 화상영어가 고시의 '컴퓨터통신교육업'에 해당하는지. 해당하지 않으면 업종별 상한 대신 "손실을 현저히 넘지 않는 위약금"(법 제32조) 일반 원칙만 남는다 → **10%를 넘기지 않는 것이 어느 쪽이든 안전.**
- **법률 확인 필요 ②**: '총계약대금의 10%'의 기준 금액(총 결제액 vs 남은 금액)과, 사은품 공제와 위약금을 합친 금액에 별도 한도가 있는지 — 고시 원문(국가법령정보센터) 별표 확인.

## 2. 환불 산식 (제안)

```
환불액 = 실제 결제액
       − ① 이용한 수업 대금      = 이용 회차 × (결제한 상품 가격 ÷ 상품 총 회차)
       − ② 사은품 공제          (조건을 모두 충족할 때만, 3절)
       − ③ 위약금              (예외에 해당하지 않을 때만, 상한 안에서, 4절)
       (0원 미만이면 0원 — 학생에게 추가 청구하지 않음)
```

| 항목 | 기준 |
|---|---|
| 회당 단가 | **결제한(할인된) 상품 가격 ÷ 총 회차.** 해지 시 정가로 다시 계산하지 않음 |
| 이용 회차에 넣는 것 | 진행된 정규·보강 수업, 학생 6시간 미만 취소·노쇼로 소진된 회차(POL-CHG-02) — **법률 확인 필요 ③**(H14: 노쇼·당일 취소를 '이용'으로 볼 수 있는지) |
| 이용 회차에 넣지 않는 것 | 강사 사유 취소·노쇼, 보상 수업(A13), 이월받은 수업(이전 등록에서 이미 값을 냄) |
| 적립금으로 낸 부분 | 현금 환불이 아니라 **적립금으로 복원**(POL-PAY-09) |
| 카드 결제 | 아임웹 부분 취소. **카드 수수료 공제 없음**(A35-2) |
| 계좌이체 | 학생 명의 계좌로 이체, 이체 수수료는 사업자 부담 |
| 지급 시기 | 해지 요청 확인 후 **N영업일 이내** — 법정 기한 확인 필요(④), 제안 3영업일 |
| 계산·승인 | LMS가 계산안을 보여 주고 **운영자(대표)가 확인·승인**. 자동 지급 없음. 환불 실행·승인은 대표 전용 권한(A34) |

## 3. 사은품(부가상품) 공제 기준 (제안)

**공제할 수 있는 조건 — 모두 충족해야 함**
1. **계약 전에** 사은품 품목·개별 가격·가격 근거·"중도해지 시 이 금액을 공제한다"를 고지하고, 학생이 **별도 체크로 동의**한 기록이 있다.
2. 사은품을 **실제로 제공(전달)한 기록**이 있다. 아직 보내지 않았으면 공제하지 않는다.
3. 가격이 합리적이다: **실제로 그 가격에 따로 판매하고 있거나 판매한 근거**가 있다(판매 페이지·판매 기록). 근거가 없으면 공제하지 않거나 근거 있는 금액만.
4. 학생이 반환할 수 있는 실물이고 사용하지 않은 상태로 돌려주면 공제하지 않는다(그 가치만큼 환급, 고시). **여행영어 eBook(PDF)은 전달 후 반환할 수 없는 디지털 파일**이라 전달했다면 공제 대상 — 단 1~3 충족 시.

- 여행영어 eBook: 판매가 26,900원 → **26,900원 전액 공제가 법적으로 확정된 것은 아님**(A35·H17). 독립 판매 실적·판매 페이지가 있으면 근거로 충분할 가능성이 높음 — 법률 확인 필요 ⑤.
- 프로모션마다 구성이 다르므로 **사은품 목록과 가격은 프로모션별로 기록**하고, 학생에게는 계약 당시의 목록을 보여 준다.

**학생별 기록 (LMS 설계 — 아직 구현 안 함)**

| 기록 | 예 |
|---|---|
| 프로모션 | 이름·기간·대상 상품(24주)·사은품 구성·고지 문구 판 번호 |
| 사은품 품목 | 이름, 실물/디지털, 판매가, 가격 근거(판매 URL·기록), 반환 가능 여부 |
| 학생별 제공 | 수강등록 ID, 품목, **고지·동의 시각(문구 판·해시)**, 제공일·방법(이메일 첨부·링크), 반환 여부, 환불 시 공제 금액·사유 |

- DB에서는 `promotions`·`gift_items`·`enrollment_gifts` 표를 **추가**하는 방식(기존 표 변경 없음). 동의 기록은 이미 있는 수업 안내 동의 구조(`terms_documents`·`consent_events`, 문서 해시)와 같은 방식으로 남긴다.

## 4. 중도해지 위약금 기준 (제안)

| 경우 | 위약금 |
|---|---|
| 결제 후 **7일 이내** 또는 **첫 수업 가능일부터 7일 이내** 해지 | **없음** (고시·청약철회) |
| 첫 수업 전 해지(기간 무관) | **없음** 제안 — 제공한 것이 없음 |
| **사업자 귀책**: 3영업일 안 강사 미매칭(POL-OP-13), 강사 반복 취소·노쇼, 수업 일정 보장 불가, 서비스 중단·주요 조건 변경 | **없음** |
| 학생의 질병·입원 등 불가피한 사유 | **일반 해지와 같이 위약금 부과** (2026-10-17 대표 결정, D-32) |
| 그 밖의 학생 사정 해지 | **총계약대금의 10% 이하**에서 대표가 정한 비율. 수정 제안(2026-10-17): **총계약대금의 10%를 '위약금(장기 할인 반환 포함)'으로** — 4-1 참고 |
| 4주(28일) 상품 | 계속거래 '1개월 이상' 요건 경계 — **법률 확인 필요 ⑥**. 확인 전까지 4주 상품은 위약금 없음 제안 |

### 4-1. 12주·24주 할인은 어떻게 하나 (2026-10-17 대표 질문)

- 고시의 '위약금'은 **이름과 관계없이 해지 때문에 청구하는 돈 전부**(이미 제공한 수업 대금 제외)다. 따라서 해지 시 "할인받은 만큼 돌려받기(정가 재산정)"도 위약금에 포함될 가능성이 높다 → **할인 반환 + 위약금을 합쳐 상한(총계약대금 10%) 안**이어야 한다 (법률 확인 필요 ②). 따로따로 둘 다 받으면 상한을 넘을 위험이 크다.
- 실제 할인 규모(현재 가격표, 50분 주2회 4주 355,000원 기준):

| 상품 | 결제액 | 정가 대비 할인 | 총계약대금 10% |
|---|---|---|---|
| 12주 (24회) | 1,011,750원 | 53,250원 (5%) | 101,175원 |
| 24주 (48회) | 1,973,500원 | 156,500원 (5% + 5만 원) | 197,350원 |

- **총계약대금 10%가 두 상품 모두 할인액보다 크다.** 그래서 할인을 따로 되돌려받는 계산을 만들지 않고 **위약금 = 총계약대금의 10%(장기 할인 반환 포함)** 하나로 두는 것이 가장 단순하고, 할인 손실도 충분히 메운다.
- 비교 — 24주, 8회 수강 후 해지 (eBook 공제 동의·전달 완료):

| 방식 | 들은 수업 대금 | 공제 | 환불 |
|---|---|---|---|
| A. 위약금 총계약대금 10% (수정 제안) | 8 × 41,115 = 328,917 | eBook 26,900 + 위약금 197,350 | **1,420,333원** |
| B. 위약금 남은 금액 10% (이전 제안) | 328,917 | eBook 26,900 + 164,458 | 1,453,225원 |
| C. 정가 재산정만 (위약금 없음) | 8 × 44,375 = 355,000 | eBook 26,900 | 1,591,600원 |
| D. 정가 재산정 + 총액 10% | 355,000 | eBook 26,900 + 197,350 | 1,394,250원 — **상한 초과 위험, 비추천** |

- 단, 이 10%는 '컴퓨터통신교육업' 상한을 기준으로 한 것이다. 우리 서비스가 해당하지 않는 것으로 확인되면 '실제 손실을 크게 넘지 않는' 일반 원칙으로 다시 본다 (법률 확인 필요 ①).

**계산 예 (가상 금액)**: 24주 48회 1,000,000원, 사은품 eBook 26,900원(고지·동의·전달 완료), 10회 이용 후 해지(첫 수업 후 7일 경과)
- 이용 대금 = 10 × 20,833 = 208,333원
- 남은 금액 = 791,667원 → 위약금(남은 금액의 10%) = 79,167원 *(총계약대금 기준이면 100,000원)*
- 환불 = 1,000,000 − 208,333 − 26,900 − 79,167 = **685,600원** *(총계약대금 기준이면 664,767원)*

## 5. 기존 규정과의 충돌

| 위치 | 지금 문구 | 문제 | 처리 |
|---|---|---|---|
| FAQ "환불 규정" (`src/data/faqs.json`) | "학원법 교습비 반환 기준을 따릅니다… 1/3 경과 전 2/3, 1/2 경과 전 1/2, 1/2 경과 후 환불 불가" | 학원 미등록이라 근거가 맞지 않음. **'1/2 경과 후 환불 불가'는 계속거래 '언제든 해지'와 충돌 가능**(12·24주). 달력 기간 기준(H14: 학원법도 교습시간 기준) | 6절 문구로 교체 (승인 후) |
| 같은 FAQ | "결제 수단 수수료 등 부대 비용은 환불 금액에서 제외됩니다" | **A35-2(카드 수수료 공제 안 함)와 정반대** | 삭제 |
| 수강계약서 SC1·SC2·SC3 3조 | 학원법 기준 반환 | 같은 문제 | 새 계약서 판(SC4 등)에서 교체. 기존 서명 학생은 계약대로 처리하되, **법 기준보다 불리한 부분은 법 기준 우선**(소비자에게 불리한 약정은 효력이 약함) |
| SC0A(2024-09 이전) | "수업 시작 전날까지 취소 시 100% 환불" | 새 기준과 대체로 일치(첫 수업 전 전액) | 해당 학생은 계약대로 |
| 아임웹 결제 페이지 환불 안내 | 저장소에 원문 없음 | 확인 필요 | 대표가 문구 캡처 전달 → 대조 |
| 기존 학생 | 지금까지 위약금·사은품 공제 없음 | 새로 위약금·사은품 공제를 붙이면 **불리한 변경** | **소급 금지**(POL-OP-16). 기존 계약은 위약금·사은품 공제 없이, 이용 대금만 공제 |

## 6. 수정 문구 초안 (승인 후 게시 — 지금은 초안)

### FAQ "환불 규정이 어떻게 되나요?"

> 수강 중 언제든 환불을 요청하실 수 있어요.
>
> **· 첫 수업 전이거나, 결제 후 7일 이내라면** 이용한 수업을 뺀 금액을 위약금 없이 돌려드려요. (첫 수업 전이면 전액)
> **· 그 밖의 경우**: 결제 금액 − 이미 들은 수업 금액 − 위약금(남은 금액의 10%) − 공제 동의한 사은품 금액
>
> ※ 들은 수업 금액은 **결제하신 상품 가격 기준의 회당 금액**으로 계산해요. (정가로 다시 계산하지 않아요)
> ※ 강사 사정으로 진행되지 못한 수업·보상 수업은 들은 수업에 포함하지 않아요.
