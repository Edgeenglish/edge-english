학생 카카오 로그인 시안

학생 로그인 7번 중 6번이 카카오톡 안 브라우저였습니다(11/8 운영 기록). 카카오 로그인으로 이메일 코드를 기다리고 옮겨 적는 일을 줄이려는 시안입니다(몇 번 누르는지는 시험에서 확인). 대상은 학생만이고, 강사·운영진 로그인은 그대로입니다.

대표 결정 4가지

  1. ① 카카오 계정을 학생에게 어떻게 연결할까요?
    A (추천) 처음 한 번만 등록 이메일 코드로 본인 확인 → 그때 카카오 계정이 자동 연결. 다음부터 카카오 버튼만.
    B 카카오 계정 이메일이 등록 이메일과 같으면 바로 연결. 카카오 '비즈 앱' 전환·이메일 동의항목 신청이 필요하고, 학생이 다른 이메일로 등록했으면 결국 A처럼 해야 함.
  2. ② 로그인 화면 순서
    카카오 버튼 맨 위 (추천) / 이메일 코드를 위, 카카오를 아래
  3. ③ 지금 학생 13명 안내
    다음 로그인 때 자연스럽게 (추천) — 이미 로그인된 학생은 안 바뀜. 화면 4의 홈 '내 정보' 줄에서 언제든 [카카오 연결] 가능 / 따로 톡 안내도 보냄
  4. ④ 영어 화면(해외 학생)에도 카카오 버튼을 보일까요?
    보임 (추천) — 해외 학생도 카카오톡으로 링크를 받음 / 한국어 화면에만

흐름 (A안) — 계정은 이메일 확인으로만 찾고, 카카오는 그 계정에 붙이기만

[카카오로 로그인]→연결 안 된 카카오: 계정 안 생김 (새 가입 막힘)→ 등록 이메일 코드로 기존 계정 로그인→그 계정에 카카오 붙이기 (linkIdentity)→ 홈 (또는 보강 날짜 고르기 링크)
  • 카카오 버튼을 먼저 눌러도 새 계정은 만들어지지 않음 — 시험·운영 모두 '새 가입 막힘' 켜져 있음(11/9 확인). 연결은 항상 이메일로 로그인된 기존 계정에만 붙음 (ChatGPT 검수 1번과 같은 순서)
  • 학생 번호·수강권·수업·보강·변경권은 기존 로그인 계정에 그대로 연결돼 있고, 카카오는 같은 계정의 로그인 방법만 하나 늘림 → 시험에서 연결 전·후 학생 번호와 화면 내용이 같은지 확인
  • 두 번째부터: [카카오로 로그인] → 바로 홈. 보강 바로가기 링크(?makeup=)는 카카오를 거쳐도 같은 화면으로 돌아옴
  • 이메일 로그인은 그대로 둠 — 카카오 없는 해외 학생은 지금처럼 이메일 코드

문의: 카카오톡 채널 엣지영어

지금 로그인 화면처럼 가운데 카드 하나(폭 400px). PC에서 [카카오로 로그인]을 누르면 카카오 로그인 창(QR 또는 카카오 계정 입력)이 열림. 2~7번 화면도 같은 카드 안에서 바뀜.

대표가 해 주실 일 (A안 승인 뒤)

  • 카카오 디벨로퍼스(developers.kakao.com)에 엣지영어 카카오 계정으로 로그인 → 앱 만들기 '엣지영어' → REST API 키 · 카카오 로그인 Client Secret 두 값 확인 (값은 채팅에 붙이지 말고 제가 안내하는 Supabase 화면에 직접 입력)
  • Redirect URI 2개 등록: 시험용·운영용 Supabase 주소 — 정확한 값은 승인 뒤 복사용으로 드림
  • 동의항목: A안은 닉네임만(필수 최소). B안이면 비즈 앱 전환 + 이메일 동의항목 추가

그 뒤 제가: 시험 Supabase에 카카오 켜기 + '직접 연결(manual linking)' 켜기 → 시험 주소(lms-test)에서 실제 휴대폰 카카오톡 안·사파리·PC 확인 → 결과 공유 → 운영 승인. DB 표 변경 없음 예정(로그인 설정·로그인 화면 코드만).

확인한 것 / 미확인

  • 확인시험·운영 둘 다 지금 카카오 꺼짐, 이메일만 켜짐, 새 가입 막힘(disable_signup) — 각 프로젝트 공개 설정 조회(11/9)
  • 확인Supabase는 카카오 로그인을 기본 지원하고, 이메일 없이 쓰는 'Allow users without an email' 설정과 로그인한 사용자에 카카오를 붙이는 직접 연결(linkIdentity)을 제공 — Supabase 공식 문서
  • 확인카카오 이메일 동의항목은 비즈 앱 전용 — Supabase 공식 문서·카카오 디벨로퍼스
  • 미확인'새 가입 막힘' 상태에서 직접 연결이 되는지 → 시험 환경에서 첫 번째로 확인. 안 되면 대안 시안을 다시 드림
  • 미확인이메일 동의항목 없이 Supabase가 카카오에 이메일 권한을 요청해 오류가 나는지 → 시험에서 확인
  • 미확인카카오톡 안·사파리·PC 각각 실제 몇 번 눌러야 되는지 → 시험에서 세 곳 모두 확인 전까지 '한 번 누르기'로 단정하지 않음
  • 추정'로그인 매번 뜸'의 원인(아이폰이 오래 안 쓴 사이트 저장 정보 삭제 등)은 카카오 로그인으로 사라지지 않음. 다만 다시 로그인할 때 코드 대신 버튼 한 번으로 줄어듦
