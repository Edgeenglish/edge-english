# 21. 첫 시범 학생 추천·입력 준비 (2026-10-27)

근거: 학생 수강현황 시트 12개·Olivia Class Record(Teacher Info·Student Info·Class Record)를 **읽기만** 해서 정리(2026-10-27 0시 KST 기준). 시트는 수정하지 않음. 이 문서는 저장소에 남으므로 이름은 가운데 글자를 O로 가림(실제 이름은 대표 대화창에만).
[`20-pilot-proposal.md`](20-pilot-proposal.md) 의 단계 1(시범 강사·학생 입력) 준비. 운영 DB 입력은 대표 승인 뒤.

## 1. 재등록이 가까운 후보 비교
| | 정O연 | 서O정 | 송O나 |
|---|---|---|---|
| 강사 | Olivia | Olivia | Olivia |
| 상품·일정 | 12주 · 주2회 화/목 21:30 · 40분 | 12주 · 주3회 월/수/금 22:00 · 20분 | 12주 · 주2회 수/금 09:00 · 40분 |
| 종료일 (시트) | 10/29(목) — 계산 10/26 + 강사 휴가 연장 | 10/30(금) — 계산 10/25 + 강사 휴가 연장 | 11/13(금) — 계산 11/10 + 이월 2회 |
| 남은 수업 | 10/27·10/29 휴가 보강 2회(확정) → 끝나면 남는 것 0 | 10/28 정규, 10/29 보강, 10/30 강사 취소(보강 10/29로 적힘) — **줄 번호·보강 날짜가 엇갈림** | 정규 4회 + 이월 2회(11/11·11/13) |

| 강사 충돌 검증 | 좋음: 같은 화/목에 Olivia 20:00(이O민)·22:20(김O민, 끝나고 딱 10분) | 보통 | 보통 |

**추천: 정O연.** 재등록 전 기록이 10/29에 깨끗하게 끝나서 새 기간을 이월 없이 시작함 → 시트와 맞춰 볼 것이 가장 적음. 같은 요일 앞뒤에 Olivia 다른 수업이 있어서 휴식 10분 검사도 실제로 확인됨.
서O정은 시트 정리 뒤 2번째, 송O나는 이월·서머타임 검증용 3번째.
참고: 김O민(Olivia 학생, 4주)은 10/24에 이미 끝남(Class Record에는 Active) — 재등록 여부에 따라 같은 방식.

## 2. 재등록 전후 이어짐 — 검증 기준 (재등록 자동 처리는 실행하지 않음)
- **재등록 전(시트 원본, 그대로 유지)**: 3번째 기간 9/29~10/26, 강사 휴가 보강 2회로 10/29까지, 변경권 0/2, 이월 남은 것 0, 적립금 5,000원
- **LMS에 넣는 것 = 새 수강권만**: 기존 학생 입력 화면에 새 상품·새 수강 시작일(= 첫 정규 수업일, 기존 규칙), 지금 기간 1, 변경권 = 주2회 기본 2, 미완료 보강·추가 수업 없음, 시트 총 수/진행 수 = 새 등록 기준
- **LMS가 계산해야 하는 값** (화/목 그대로 11/3(화) 시작일 때 — 날짜·상품은 재등록 때 대표가 확인)
  - 4주: 11/3~11/30, 변경권 2
  - 12주: 11/3~11/30 · 12/1~12/28 · 12/29~1/25, 기간마다 변경권 2
- 확인할 것: ① 이전 기간 남은 변경권(0)이 넘어오지 않고 새 기간에 2가 새로 생김 ② 기간 날짜가 시트 새 기간과 같음 ③ 10/30~11/2(수업 없는 날)에 정규 수업이 생기지 않음 ④ 적립금 5,000원은 LMS에 넣지 않음(시트 기준, 20번 5절)
- 재등록 처리 기능(이전 등록과 연결)은 아직 없음 — LMS에는 새 등록 하나로만 들어감. 이전 기록은 시트에

## 3. 운영 DB 입력에 필요한 최소 정보
**강사 Olivia** — 표에 이름·나라·시간대 3개만. Class Record Teacher Info 기준: 일본 미야자키, KST와 시차 0 → `Asia/Tokyo` (학생 시트의 '미국'은 국적 표기로 판단)
```sql
-- 운영 edgeenglish-lms 에서만. 이미 있으면 아무것도 안 함

on conflict (name) do nothing;
select id, name, country, timezone from tutors;
```
- 휴무: Olivia 10/30(금) 강사 취소(서O정·황O영 시트) — 새 기간 전이라 넣지 않음. 11월 이후 휴무 없음으로 판단(2026-10-27, 대표가 맡김): 시트에 11/2~11/10 Olivia 정규 수업이 그대로 있고(이O민·이O옥·황O영), 그 기간 '연장·TBD'는 모두 Benny 학생 → 11/2~11/10은 Benny 휴가
