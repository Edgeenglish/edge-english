안 2. 단계별 칸

'1 안내 보내기 · 2 학생 답 입력 · 3 강사 확인 · 4 확정' 칸이 위에서 아래로 있고, 각 칸 안에 해당 학생들이 줄지어 있음. 같은 일을 여러 학생에게 몰아서 할 때 빠름. 대신 한 학생의 진행 상황이 여러 칸에 흩어짐 (예: 김하준 4회는 3칸, 1회는 2칸).

추천 이유(안 1): 답은 학생·강사마다 따로따로 오기 때문에, 답이 왔을 때 그 학생 카드 하나만 열면 끝나는 쪽이 휴대폰에서 덜 헤맴.

함께 바뀌는 것

  • 학생 선택 안내 ①·②의 휴무 강사 이름 → '담당 강사님' (학생은 자기 강사를 알기 때문에 이름을 써도 되면 그대로 둠 — 확인 1)
  • '보강 후보' → '보강 가능한 날짜'
  • 보강 시간 최대 2개: 강사 휴무 화면 + 수업 변경 화면(지금은 '+ 시간'으로 제한 없음)

대표 확인 3가지

  • 1. 학생에게 가는 글에는 휴무 강사 이름(Emma)을 그대로 둘까요, '담당 강사님'으로 바꿀까요?
  • 2. 화면 흐름: 안 1(학생 카드, 추천) / 안 2(단계별 칸)
  • 3. 바뀌는 글 ①·② 문구 이대로 괜찮은지
