# 인증·알림 메일 발송 서비스 비교 (POL-AC-06, D-28 후속) — 2026-10-17

목적: 학생·강사 **이메일 6자리 코드 로그인**(Supabase Auth)과 **보강 리마인더**(학생, 24시간·2시간 전) 발송.
Supabase 기본 메일은 팀 멤버 주소에만·시간당 약 2통이라 실제 운영에 못 씀 → 외부 발송 서비스(SMTP) 1곳이 필요.

## 예상 발송량 (가정)
- 활성 학생 100명 기준: 로그인 코드(로그아웃·만료 때만, 1인 월 2~4통) + 보강 리마인더(보강 1건당 2통) ≈ **월 500~1,000통**, 몰리는 날 하루 50~100통.
- 학생 수가 늘면 비례해서 늘어남.

## 비교 (가격은 2026-10 제3자 자료 기준 — 가입 전 공식 가격표로 다시 확인)

| | Resend | Brevo | Amazon SES | Postmark |
|---|---|---|---|---|
| 무료 | 월 3,000통·**하루 100통**·도메인 1개 | **하루 300통** (월 최대 약 9,000) | 신규 계정 12개월 월 3,000통 | 월 100통 (시험용 수준) |
| 유료 시작 | 월 $20 (5만 통) | 월 $9~25 (5천~2만 통, 하루 제한 없음) | 1,000통당 $0.10 | 월 $15 안팎 |
| Supabase 연결 | **공식 연동 있음** (버튼으로 SMTP 설정) | SMTP 정보 직접 입력 | SMTP 정보 직접 입력 + AWS 발송 제한 해제 신청 필요 | SMTP 정보 직접 입력 |
| 설정 난이도 | 쉬움 | 쉬움 | **어려움** (AWS 계정·권한·심사) | 쉬움 |
| 메일에 업체 로고 | 없음 | 무료·저가 요금에 로고가 붙을 수 있음(마케팅 메일 기준, 인증 메일 적용 여부 확인 필요) | 없음 | 없음 |
| 도메인 인증(DNS) | SPF·DKIM 레코드 추가 (호스팅케이알) | 같음 | 같음 | 같음 |

## 추천: **Resend 무료로 시작**
- Supabase 공식 연동이 있어 설정이 가장 단순하고(운영 시간·유지보수 최소), 지금 예상량(월 1천 통 이하)은 무료 범위.
- 위험: **하루 100통 제한** — 학생이 늘거나 하루에 몰리면 막힘. 그때 월 $20 요금제로 올리면 됨 (발송 업체 교체 불필요).
- 대안: 비용을 끝까지 0원으로 오래 쓰고 싶으면 Brevo(하루 300통). 대신 로고 표시 여부를 먼저 확인해야 함.
- Amazon SES는 가장 싸지만 AWS 설정이 어려워 지금 단계에는 맞지 않음.

## 결정 후 순서 (대표 승인 필요, 기존 DNS 레코드는 바꾸지 않고 추가만)
1. 업체 가입 (support@edgeenglish.kr)
2. 발송 도메인 인증: 업체가 알려 주는 SPF·DKIM 레코드를 **호스팅케이알 DNS 관리**에 추가 (D-28)
3. 시험용 Supabase 프로젝트의 SMTP 설정에 연결 → 이메일 코드 로그인 실물 시험(5-5)
4. 결과 확인 후 운영 프로젝트에 같은 설정

출처: Resend·Brevo·SES·Postmark 가격은 제3자 정리 자료(dupple.com, costbench.com, wpmailsmtp.com, codenote.net 등, 2026)를 참고했고 공식 가격표는 가입 전에 다시 확인한다.
