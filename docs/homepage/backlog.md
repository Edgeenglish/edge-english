# 홈페이지 개선 과제 (LMS와 별도 관리)

LMS 개발과 섞지 않는다. 브랜치·배포·시안 승인도 따로 진행한다.

## 핵심 목표

인스타그램 릴스의 높은 조회수를 **실제 수강 상담(카카오톡 채널)과 등록**으로 연결한다.

## 완료

| 날짜 | 내용 |
|---|---|
| 2026-10-15~16 | 수강후기 섹션을 홈페이지 상단으로 이동, 후기 관리 화면·자동 반영 (`docs/reviews-setup.md`) |

## 과제

### H-1 · 메인 '실제 수업 모습' 섹션 (우선)
- 내용: 실제 강사·탠저린이 수업하는 인스타그램 릴스를 메인에 보여 줌 → 바로 아래 카카오톡 상담 버튼
- 진행 방법: 서로 다른 시안 3개(배치·동선 차이) → 대표 선택 → 개발 → 미리보기 확인 → 승인 후 배포
- 확인할 것
  - 사용할 릴스 목록(링크)과 순서 — 대표가 정함
  - 영상에 나오는 강사·학생의 홈페이지 게시 동의 (인스타 게시 동의와 별개일 수 있음). 후기와 마찬가지로 강사 개인 홍보 지양 원칙과 맞는지
  - 표시 방식: 인스타그램 공식 임베드(인스타 계정·쿠키 의존, 느릴 수 있음) vs 영상 파일 직접 올리기(빠르고 모바일 자동 재생 가능, 파일 관리 필요) — 시안 단계에서 장단점 비교
  - 휴대폰에서 세로 영상이 화면을 다 차지하지 않게, 소리 꺼진 자동 재생 + 탭하면 소리
  - 페이지 속도(영상 용량), 검색 노출
- 측정: 섹션 노출 → 카톡 버튼 클릭 수 (Vercel Analytics 또는 간단한 클릭 기록) — 측정 방법도 시안과 함께 제안

### H-2 · 정책 문구 정리 (정책 결정 후)
- FAQ '수강권 사용 기한'의 "(4주~12주)" → 24주 포함
- FAQ 장기 연기·이월 문구를 정책 기준표 결정(D-1a, D-3)에 맞춤
- 수업료 페이지 탭 이름 '개월' → '주' 표기 검토
- 근거: `docs/lms/policy/conflicts.md` CF-01·05·11

### H-3 · 기타 아이디어 (미정)
- 릴스 유입용 랜딩(인스타 프로필 링크 전용 페이지): 후기 + 수업 모습 + 가격 + 상담 버튼만
- 이벤트 페이지의 마감 이벤트 정리
