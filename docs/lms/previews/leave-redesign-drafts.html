  2. Q2 이름 C1 — 10/29 정한 단계 이름(수업별 대체 강사 찾기 › 학생한테 기존 강사 휴무 안내하기 › 학생이 원하는 수업 방향 입력 › 확정 안내 보내기)은 단계 줄이 없어지면 버튼 이름으로 씀: [강사에게 문의] [학생에게 휴무 안내] [학생 답 기록] [확정 안내 보내기]. ChatGPT안 '학생 선택 기록'은 '학생 선택' 금지 규칙과 부딪혀 '학생 답 기록'으로 했어요. 괜찮을까요?
  3. Q3 수강기간 연장 C2 — 학생 안내에 세 번째 선택지로 따로 둘까요? 지금 정책은 보강이 종료일 뒤로 잡히면 자동 연장이라 시안에는 안 넣었어요. (권장: 지금처럼 자동, 선택지 안 만듦)
  4. Q4 수업 인계 C10 — 대체강사에게 넘길 교재·페이지·Docs가 어디 있나요? (강사 Class Record 시트 · 학생 Docs 노트 · 교재 목록 중) 정해지면 '수업 인계' 칸을 채워요. 지금은 칸 자리만.
  5. Q5 대시보드 — 휴무 줄을 '처리할 일 / 답 기다리는 일'로 나눠 보이기(R25·R29)는 이 흐름 확정 뒤 대시보드 작업 때 같이 할까요? (권장: 예)

휴대폰

무엇이 바뀌나

  • 같은 날짜를 위·아래 두 번 읽지 않음: 수업 한 줄에 상태 + 버튼(R11·R15)
  • 대체강사 목록은 한 곳만, 날짜마다 '평소 가능시간과 일치 / 평소 시간표 밖 · 문의 필요 / 다른 수업과 겹침(불가)'(R12·R13)
  • 후보 고름 → [강사에게 문의] 보냄 → 답 기다림. 보내기 전엔 '문의 보내기 전'(R2, 오늘 고침)
  • 같은 강사에게 여러 학생 수업을 한 메시지로 묻고, 답은 수업마다 체크(처음엔 체크 없음)(R17·R3)
  • 어느 때든 [휴무 먼저 안내](R19). 일부만 정해져도 확정·안내 가능(R20)
  • 확정 안내는 학생 글(맡는 강사 Meet 링크 자동) + 강사 글 한 화면, 둘 다 보내야 완료(R21·R4)
  • [← 뒤로]는 화면만 옮김. 처리 무르기는 [처리 되돌리기] + 확인창(R1, 오늘 고침)
  • 끝에 [다음 학생 ›], 답 기다리는 수업이 남아도 넘어감(R24)
