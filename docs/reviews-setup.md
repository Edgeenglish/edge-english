# 수강후기 시스템 설정 안내

후기는 Google 시트에 저장되고, 홈페이지는 5분마다 공개 후기를 자동으로 가져옵니다.
후기를 등록·수정·숨김·삭제할 때 코드 수정이나 재배포는 필요 없습니다.

```
카카오톡 후기 → 관리 화면(휴대폰/PC) → Google 시트 '후기' 탭
                                         ↓ (공개 후기만)
                               공개 피드(Apps Script) → 홈페이지 (5분마다 갱신)
```

| 구성 | 위치 | 누가 볼 수 있나 |
|---|---|---|
| 후기 시트 | Google 드라이브 (support@edgeenglish.kr) | 관리자만 |
| 관리 화면 | `apps-script/admin/` (시트에 연결된 Apps Script) | 관리자 계정으로 로그인했을 때만 |
| 공개 피드 | `apps-script/feed/` (별도 Apps Script) | 공개 후기만 내보냄 |
| 피드 주소 | Vercel 환경변수 `REVIEWS_FEED_URL` | 홈페이지 서버만 (브라우저·GitHub에 없음) |

모든 작업은 **support@edgeenglish.kr** 계정으로 로그인한 상태에서 하세요.

---

## 1. 후기 시트 + 관리 화면 만들기 (약 7분)

1. [sheets.new](https://sheets.new) 에서 새 시트를 만들고 이름을 `엣지영어 수강후기`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다. 왼쪽 위 프로젝트 이름을 `후기 관리`로 바꿉니다.
3. `Code.gs` 의 내용을 모두 지우고, 이 저장소의 `apps-script/admin/Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 **파일 옆 + → HTML** 을 누르고 이름을 `Admin` 으로 입력한 뒤, 기본 내용을 지우고 `apps-script/admin/Admin.html` 내용을 붙여넣습니다.
5. 저장(💾) 후, 위쪽 함수 선택 상자에서 `setup` 을 고르고 **실행** 을 누릅니다.
   - 권한 요청 창이 뜨면 support@edgeenglish.kr 선택 → **고급 → 후기 관리(으)로 이동** → **허용**.
     (직접 만든 스크립트라 Google 확인을 받지 않았다는 안내가 나오는 것이 정상입니다.)
   - 시트에 `후기` 탭이 생기고 기존 홈페이지 후기 6개가 들어가면 성공입니다.
6. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **나만**
   - **배포** → 나오는 **웹 앱 URL** 이 관리 화면 주소입니다. 잘 보관하세요.
7. 휴대폰에서 그 주소를 열고 (support@edgeenglish.kr 로그인 필요)
   - 아이폰 Safari: 공유 버튼 → **홈 화면에 추가**
   - 안드로이드 Chrome: ⋮ → **홈 화면에 추가**

## 2. 공개 피드 만들기 (약 5분)

1. [script.new](https://script.new) 로 새 Apps Script 프로젝트를 만들고 이름을 `후기 공개 피드` 로 바꿉니다.
2. 내용을 모두 지우고 `apps-script/feed/Feed.gs` 내용을 붙여넣습니다.
3. 맨 위 `SPREADSHEET_ID` 의 `여기에_후기_시트_ID_붙여넣기` 를 후기 시트 ID로 바꿉니다.
   - 시트 주소 `https://docs.google.com/spreadsheets/d/`**`이 부분`**`/edit` 이 ID입니다.
4. 저장 후 함수 선택 상자에서 `doGet` 을 고르고 **실행** → 1번과 같은 방법으로 권한 허용.
5. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → **웹 앱 URL** 복사
6. 복사한 주소를 브라우저에서 열어 `{"reviews":[...` 로 시작하는 글자가 보이면 성공입니다.
   이 주소는 공개 후기만 보여주므로 노출되어도 비공개 후기는 새지 않지만, 외부에 공유하지는 마세요.

## 3. Vercel에 피드 주소 등록 (약 3분)

> 즉시 반영을 쓰려면 아래 2번에서 `REVIEWS_REFRESH_SECRET`(아무도 모르는 긴 글자)도 같이 등록하고,
> 관리 화면 `Code.gs` 맨 위 `REFRESH_SECRET` 에 같은 값을 넣은 뒤, 편집기에서 `checkSite` 를 한 번 실행(권한 허용)하고
> **배포 → 배포 관리 → ✏️ → 새 버전 → 배포** 로 관리 화면을 갱신합니다.

1. Vercel → 엣지영어 프로젝트 → **Settings → Environment Variables**
2. Key: `REVIEWS_FEED_URL` / Value: 2번에서 복사한 웹 앱 URL / Environments: **Production, Preview** 모두 체크 → **Save**
3. **Deployments** 탭 → 가장 최근 배포의 ⋯ → **Redeploy** (환경변수는 다음 배포부터 적용되므로 이때 한 번만 필요)

설정 전이거나 Google이 잠시 응답하지 않을 때는, 기존 후기(`src/data/reviews-fallback.json`) 또는 마지막으로 받아 둔 후기가 그대로 보입니다.

## 운영 방법

- **등록**: 관리 화면 → `+ 후기 등록` → 카톡 후기 붙여넣기 → 이름(실명 입력 시 자동으로 김O수처럼 저장) → 날짜(과거 날짜 가능) → 등록
- **직업 버튼 추가·변경**: 시트 `직업` 탭 A열에 이름을 추가·수정·삭제하면 관리 화면 직업 버튼이 바뀝니다. ('직접 입력' 버튼은 항상 맨 끝에 있음)
- **담당 강사** (선택): 버튼 한 번 누르기. 홈페이지에는 표시되지 않고 시트에만 저장. 강사가 바뀌면 시트 `강사` 탭 A열의 이름을 고치면 버튼이 바뀝니다.
- **대표 문장**: 후기 내용에서 문장을 길게 눌러 선택 → `선택한 문장을 대표 문장으로` (선택 사항)
- **숨기기**: 목록에서 공개 스위치 끄기 (다시 켜면 공개)
- **수정·삭제**: 목록에서 후기를 눌러 수정 화면으로
- 홈페이지 반영: 등록·숨김·삭제 즉시 (관리 화면 위쪽에 ✅ 반영 완료 / ⏳ 반영 중 표시). 즉시 반영이 안 되는 상황에서도 5분 안에 자동 반영
- PC에서 여러 개를 몰아서 넣을 때는 시트 `후기` 탭에 직접 붙여넣어도 됩니다.
  (브랜드는 `엣지영어`/`영붙캠`, 날짜는 `2026-10-15` 형식, 공개는 체크박스, 이름은 실명이어도 홈페이지에는 가려서 표시)
- 기존 후기 6개는 받은 날짜를 몰라 날짜가 비어 있습니다(목록에 빨간 `날짜 없음`). 날짜를 넣어 주세요.

## Apps Script 코드를 나중에 고쳤을 때

코드를 붙여넣고 저장한 뒤 **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**.
이렇게 하면 주소가 바뀌지 않습니다. (`새 배포` 를 누르면 주소가 바뀌니 주의)
