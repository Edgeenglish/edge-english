홈페이지 회원가입·로그인 시안 (1단계)

정책 원본 H26(146) · 아이디 = 이메일 · 비밀번호 로그인 · 기존 학생·강사는 재가입 없이 비밀번호만 만들기. 코드·DB·로그인 설정은 바꾸지 않았습니다.

확정 (정책 원본 H26(150), 11/11)

  • 아이디 = 이메일 · 가입 칸 이름·이메일·비밀번호·필수 동의 2개 · 비밀번호 8자 이상 · 가입할 때 메일 6자리 코드
  • 기존 학생·강사: 재가입 없이 '비밀번호 만들기·찾기'에서 비밀번호만 (지금 계정·수강 기록 그대로) · 메일 코드 로그인은 로그인 화면에서 뺌
  • 카카오·네이버 로그인 첫 공개부터 포함 · 첫 소셜 로그인 '처음이에요 / 이미 회원이에요' · 이미 회원이면 기존 계정으로 로그인한 뒤에만 연결
  • 자동 연결은 인증된 같은 이메일만 · 헤더 말풍선 '회원가입 없이 간편 신청하기' 없앰
  • 공개: 이메일·카카오·네이버 모두 완성 + QA 통과 뒤 (그 전까지 새 주소 공개·주소 이전 보류)
