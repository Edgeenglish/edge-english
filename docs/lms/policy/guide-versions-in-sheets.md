# 학생 수강현황 시트 속 필독안내서 판 확인 (Q-7, 2026-10-16)

- 방법: Drive에서 제목에 '수강현황'이 들어간 시트 **55개**를 **읽기 전용으로 내보내기(xlsx)** 해 그 안의 이미지 파일을 꺼내고, 대표가 보내 준 현행 안내서(G20260709) 2장과 그림 비교 → 다른 그림은 직접 읽어 문구 대조. **시트·Drive는 아무것도 고치지 않음.** 내려받은 파일은 분석 후 삭제.
- 이 문서에는 학생 이름·파일 ID를 적지 않는다. 건수와 시트 **생성 월**만 적는다.
- 55개 = 실제 학생 시트 52개 + 샘플 3개. 실제 52개 중 같은 학생 파일이 2개씩인 경우가 2명 → 실제 학생 약 50명.

## 1. 결론

1. **모두 같은 판이 아니다.** 시트 안에서 안내서가 **5가지 판**으로 발견됨 (예전 1장짜리 4종 + 현행 2장 세트).
2. **중간에 교체한 것으로 보인다.** 2025-12~2026-06에 만든 시트 일부에 현행판(2026-07-09)이 들어 있음 → 나중에 이미지를 바꿔 끼웠거나, 현행판이 Drive 파일 날짜보다 먼저 있었음. 같은 시기에 만든 다른 시트에는 예전 판이 그대로 남아 있어 **교체는 일부 시트에서만** 이뤄짐.
3. **2026-06-22 이후에 만든 시트는 모두 현행판.** (샘플 1개는 이미지 없음)
4. 시트에 지금 있는 이미지는 '현재 게시본'이지 **학생이 등록할 때 본 판이라는 보장이 없다.** 교체 날짜는 내보내기로는 알 수 없음 → 시트의 '버전 기록'에서만 확인 가능.
5. 카톡으로 보낸 이미지가 시트와 같은 판인지는 확인 못 함 (카톡 접근 불가).

## 5. 기록 방식

- 판 코드 GV1~GV4를 `terms_versions`(kind = guide)에 추가 (날짜 미상).
- 시트에서 확인한 사실은 `terms_deliveries`에 channel = `student_sheet`, timing = `unknown`으로 남긴다. "지금 시트에 있는 판"이지 "등록 때 본 판"이 아님을 메모에 적는다.
- 학생별 판정(유형 ②·③)과 적용 조건은 **정하지 않음** (D-22).

## 6. 대표가 확인하면 좁힐 수 있는 것 (선택)

- 현행판이 들어 있는 2025-12~2026-06 생성 시트 13개(실제 학생)의 **버전 기록**에서 이미지가 바뀐 날짜. 원하시면 대상 시트 목록은 대표 계정 Drive에만 따로 정리해 드림 (새 파일 생성이라 승인 필요).
- 카톡으로 보낸 안내서 이미지가 그때 시트 판과 같았는지.
