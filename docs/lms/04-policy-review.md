## 우선 점검 10개 항목

### 1. Sheets 중심 → Supabase DB 중심 — **충돌 → 운영자 결정으로 변경**

- PDF: "지금 시트 구조를 그대로 데이터 모델 출발점", "기존 시트와 병행 운영".
- 최신 결정: 웹앱 + Supabase(PostgreSQL)가 유일한 원본. 시트는 이관·검증·보고용.
- 수정: 시트 컬럼을 그대로 옮기지 않고 정리 (예: Master Sheet의 1·2·3차 시작·종료일 칸 → `수강등록` + `기간` 표로 분리, 이름 기반 연결 → ID 연결). 병행 운영은 **"시트로 되돌아갈 수 있게 DB → 시트 보고용 내보내기 유지"** 로 바꿈.

### 2. 수강후기 '신규 구축' — **이미 완료 (기획서 9장 해당 부분 삭제)**

- 실제: 운영자가 카톡 후기를 관리 화면(휴대폰·PC)에서 익명 등록 → 홈페이지 자동 반영. 강사명·별점 없음.
- PDF 9장의 "강사별 탭, 평균 별점, 로그인한 수강생 작성, 후기 3개 이상 강사만 탭 표시"는 현재 원칙(강사명 미표시, 받지 않은 별점 금지)과 **충돌**하므로 삭제.
- LMS와 통합: **불필요**. 후기는 익명 공개 데이터, LMS는 개인정보 데이터라 섞을수록 노출 위험만 커짐. 지금 시스템을 그대로 둔다.

### 3. '결제 → 신청서' 순서 vs '입금 대기·재안내 메일' — **충돌**

- 실제 순서(PDF도 "유지"): 결제(계좌이체/아임웹 카드) → 구글폼 신청서(입금자명 포함) → 카카오톡 채널 메시지. 수강계약서도 "결제 완료 시 동의 간주".
- 그런데 PDF 6장은 신청서 제출 **후** 결제 금액을 계산해 안내하고, 24시간 안에 입금이 없으면 재안내 메일을 보낸다 → **이미 결제한 사람에게 "입금해 주세요" 메일이 갈 수 있음.**
- 추천: 순서는 그대로 두고, 신청서 접수 상태를 '입금 대기'가 아니라 **'입금 확인 대기'** 로. 자동 재안내 메일은 만들지 않고, 운영자가 "입금 미확인" 버튼을 누를 때만 안내 메일. 금액 계산은 신청서 내용으로 **운영자 확인용**으로만 표시(입금액과 다르면 경고).

### 4. 보강 수업 재취소 — **충돌(문서 내부 모순) + 미확정**

- PDF 3-3 ②: "보강 수업도 정규 수업과 똑같이 취소·변경할 수 있다."
- PDF 10장 결정 목록: "확정된 보강을 학생이 취소할 때 재보강 여부 (추천: 재보강 불가)" — 미결 상태로 남음.
- FAQ(이미 공개): "보강 수업을 다시 취소하시는 경우, 재보강은 불가".
- 추가 발견: 재보강 불가로 정하면 **상태값 14개 중 맞는 값이 없음** (6시간 전에 취소했는데 수업이 소진되는 경우). 강사 급여 지급 여부도 함께 정해야 함.
- 코드: 두 선택지 모두 테스트로 검증해 두고, 운영자가 고르기 전에는 적용되지 않게 막아 둠 (`PendingPolicy.makeupRecancel`).

### 5. 재등록 시 이월 기한 — **충돌 (3가지 버전)**

| 자료 | 기한 |
|---|---|
| FAQ, 안내서 | 수강 종료일 **당일** 밤 12시까지 |
| PDF 3-3·7장 | 종료일 **다음 날** 23:59 |
| 수강계약서 | 종료 후 **최대 1주일** 이내 |

- 학생이 서명(결제로 동의)하는 문서는 수강계약서이므로, 계약서보다 엄격한 기준으로 운영하면 분쟁 시 불리할 수 있음.
- 관련 미결: PDF 7장 '재등록 대기 기간(1주 또는 2주)' — 이월 기한과 같은 날로 맞추면 규칙이 하나로 줄어듦.

### 6. 강사 늦은 취소 시 학생 보상 — **미확정**

- PDF·상태매핑표: 'Tutor canceled late' = 학생 수업 소진 없음, 수강기간 내 보강, 강사 인센티브 영향. **쿠폰·추가 보상은 없음.**
- 급여정책: 늦은 취소가 있으면 +$2 인센티브 없음, 반복 시 추가 공제 가능.
- 수강계약서·FAQ: 강사 늦은 취소에 대한 학생 보상 언급 없음 (FAQ: "강사 사정 → 차감 없이 보강").
- 빈틈: 기간 끝 무렵 강사가 취소하면 학생이 보강을 잡을 시간이 없을 수 있음.

### 7. 강사 노쇼 보상 수업 사용 기한 — **미확정**

- PDF: 보강 1회 + 보상 1회, 사용 기한 미정 (추천: 일반 보강처럼 수강 기간 안, 지나면 소멸).
- 강사계약서 6-5: 노쇼 시 보강 + 보상 1회, **보상 수업은 강사 급여·인센티브 없음** → 상태가 '보강 완료'여도 보상 수업이면 급여 미지급으로 처리해야 함 (DB 설계에 반영).
- 노쇼 판정 기준도 자료마다 다름: PDF는 "5분 뒤 신고 버튼, 운영진 확정 전 강사가 들어오면 지각", 옛 인센티브 메모는 "10분 이상 지각은 노쇼".

### 8. 강사 급여·인센티브 수치 — **최신 문서끼리는 일치 / 옛 자료와 충돌 / 세부 미확정**

| 항목 | PDF | 급여정책(2026-03-27) | 강사계약서(2026-08-24) | 옛 자료 |
|---|---|---|---|---|
| 기본 시급 | $11 | $11 | $11 | 메모 $14, 채용공고 수습 $15 → $16, 페이 시트에 $15 표 |
| 최대 | $17 | $17 | $17 | 공고 $17 |
| 10분 안 기록 90% | +$1.50 | +$1.50 | (정책 문서 따름) | 메모 +$0.5 |
| 노쇼 없음 | +$2 | +$2, 반복 시 회당 $1 추가 공제 가능 | 반복 노쇼 공제 가능 | |
| 늦은 취소 없음 | +$2 | +$2, 반복 시 같은 공제 | | |
| 정시 90% | +$0.50 | +$0.50 | | |
| 수업 단위 | 총 분 ÷ 30 내림 | 같음 | | |

- 미확정: ① 옛 조건($15·$16)으로 계약한 강사가 아직 있는지, ② 반복 노쇼·늦은 취소 추가 공제 적용 여부, ③ 금액 계산 끝자리(페이 시트는 센트 이하 버림), ④ '정시'를 누가 판정하는지(강사 자기 선택 + 학생 신고), ⑤ 기록 시각 측정(현재 시트에는 기록 시각 칸이 없음).
- 원칙: 확정 전에는 자동 정산 금액을 확정하지 않음. 1차 정산 기능은 **"계산 미리보기 + 운영자 승인"** 만.

### 9. 강사 장기 휴무·대체 강사·기간 연장 — **미확정 + 개선 제안**

- PDF: 상태 'Tutor long-term leave → 수강기간 연장', 연장 한도 미정 (예: 최대 1주, 길면 대체 강사).
- 강사계약서 10조: 휴무는 14일 전 서면 통보. 11조: 같은 학생 수업을 30일 안에 2회 이상 취소하면 대체 강사 배정 가능.
- 수강계약서·안내서: 스케줄이 안 맞으면 다른 강사가 보강할 수 있음. PDF는 '다른 강사 보강'을 '나중'으로 미룸 → **운영자 수동 배정은 처음부터 가능하게** 하는 것이 실제 운영과 맞음.
- 개선 제안: 강사·날짜 범위를 고르면 영향받는 수업을 학생별로 미리 보여주고, 학생별로 [대체 강사 / 기간 연장 / 보강]을 골라 한 번에 반영·되돌리기 (`src/lms/rules/leave.ts` 미리보기 구현·테스트 완료).
- **긴급: 2026-11-02~11-10 휴무는 LMS 완성 전**이므로 기존 방식(시트·카톡)으로 처리해야 함.

### 10. 수강 시작일·기간별 변경권·공휴일 — **일치 (계산 규칙) / 시트 버그 1건 / 범위 미확정 1건**

- 시작일 = 첫 정규 수업일, 28일(시작일 포함), 12주 = 3기간, 24주 = 6기간, 주말·공휴일 시작도 동일 → PDF·시트 수식·수강계약서 일치. 자동 테스트로 검증(주말·공휴일·윤년·연말 포함).
- **시트 버그: Master Sheet는 3기간(12주)까지만 계산** → 24주 학생 종료일 오류 가능.
- 변경권: 4주(28일)마다 주1회=1·주2회=2·주3회+=3, 4주마다 갱신(남은 것 이월 없음) → PDF·FAQ·안내서·수강계약서·Class Record 안내 일치.
- 공휴일: 수업은 정상 진행, 6시간 전 변경 시 변경권 차감 없음, 변경권 0개여도 가능, 보강 가능 → PDF·FAQ·공지 일치.
- 미확정: **어떤 날을 '공휴일'로 볼지** (공지는 노동절·어린이날·부처님오신날 예시). → 운영자가 공휴일 표에 직접 등록하는 방식으로 설계.
- FAQ 문구 "수강 기간(4주~12주)" 에 24주가 빠져 있음.

## Class Status 14개 ↔ Master Sheet 상태매핑표

**일치.** 14개 이름, 수강권 차감·변경권 차감·강사 페이 대상·인센티브 영향이 PDF 3-7 표와 시트가 모두 같음 (자동 테스트 `상태값 14개` 에서 시트 값과 대조). 학생용 문구는 시트가 "👉" 형식으로 조금 다를 뿐 뜻은 같음. 단, 'Student long-term leave' 학생 문구의 "최대 2주·24주만"은 위 A 항목 결정에 따라 바뀔 수 있음.
