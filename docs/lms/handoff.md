## 대표가 요청한 화면 수정 (2026-10-18, 시험하며 발견) — 한 세션에 묶어 처리, 디자인이 바뀌는 건 시안 먼저 → 대표 확정 후 코드
1. 신규 학생 등록 "거주 국가 / 도시" 칸 오류: 글자를 칠 때마다 앞뒤 공백을 지우고 `/` 로 나눠서 띄어쓰기·슬래시가 안 쳐짐 (`NewStudent.tsx` 거주 국가 / 도시 입력). 대표 요청: **칸 두 개로 나누고 둘 다 한국어로 검색해서 고르게** (국가 → 도시, 한국어 검색)
2. "사는 곳 시간대 · 현재 시각" 선택: 지금은 영어 이름 19개를 고르는 목록(`TZ`)이라 검색 불가 → **한국어(멜버른·시드니 등)·영어 둘 다로 검색**, 국가·도시를 고르면 시간대 자동 추천
3. 수강 기간 표시: "4주 (1기간 × 28일)" (`NewStudent.tsx` 수강 기간 선택·3단계·최종 확인의 "1기간")가 낯섦 → "4주 (28일)" 식으로. 정책 기준표(`policy/register.md`, POL-PER-02·03) 용어와 먼저 대조하고 다르면 대표에게 보고
4. 로그인 화면 이메일 가림 표시 `chl***@naver.com` (`src/lms/auth/login-flow.ts` `maskEmail`, `login-flow.test.ts`): `***` 가 항상 3개 → **실제로 가린 글자 수만큼** 표시 (대표 요청)
5. (참고) 강사 선택에서 필터(가능 요일·시간)를 고르면 가능 시간 데이터가 없는 강사는 모두 걸러져 "조건에 맞는 강사가 없어요"가 뜸 — 실제 강사 가능 시간이 들어오면 해결. 대표가 헷갈려 했으니 안내 문구 보강을 시안에 포함할지 확인
