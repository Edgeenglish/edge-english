# 핵심 운영정책 검토표 (승인 전 확인용)

`register.md`의 `확정` 44개 중(운영 사실 기록 POL-OP-09 포함) **수강 횟수·변경권·보강·이월·장기 연기·강사 급여·환불**에 직접 영향을 주는 **27개**만 추렸다.
같은 내용이 기준표 각 항목의 `핵심 영향 / 적용 대상 / 판본 차이` 줄에도 들어 있다 (자동 테스트가 빠짐을 검사).

**먼저 알아 둘 점**
- **(2026-10-16 저녁 갱신)** 아래 표는 정책 원본 반영 **전** 검토표다. 이월·보강 재변경·지각·고정 시간·공휴일·장기 연기·강사 노쇼/취소 보상·적립금은 대표가 Google Docs 정책 원본에서 확정했다(신규·갱신 등록부터, 소급 없음) → [`official-source.md`](official-source.md), `register.md`의 ✅. 기존 계약 판본별 차이는 이 표가 계속 기준이다.
- (정책 원본 반영 전 기준) **실제 승인(✅)된 정책은 0개.** `◐`는 대표가 대화(2026-10-16)에서 말했거나 기획서(2026-10-11) 결정 목록에 체크한 것으로, 정식 승인이 아니다.
- `확정`은 "근거 문서끼리 일치하고 실제 적용 중"이라는 뜻이며, **적용 대상에 적힌 판본에만 해당**한다. 27개 중 **계약 판본에 따라 내용이 달라지는 것 16개**, 판본과 관계없지만 **근거가 계약서가 아니라 안내문·내부 기준뿐인 것 9개**, 어느 문서에서나 같은 것 2개.
- **안내서만 받은 학생 (2026-10-16 추가)**: 아래 '적용 대상' 판본(SC0A~SC2)은 계약서를 받은 학생에게만 해당한다. 2026년 초부터 계약서 없이 필독안내서만 받은 학생(유형 ②)과 예전 계약 후 재등록 때 안내서만 받은 학생(유형 ③)에게 어떤 조건이 적용되는지는 **정하지 않았다** (POL-OP-10·11, D-22, 법률 미확인). 안내서와의 항목별 차이: [`guide-2026-07-09-review.md`](guide-2026-07-09-review.md).
- **장기 연기·환불에는 `확정` 정책이 없다** (모두 `검토 중`, 맨 아래 표).
- 판본 코드: 학생 `SC0A`(2024-09 이전) `SC0B`(2024-11) `SC0C`(2025-05) `SC1`(2025-10~12) `SC2`(2026-01~) `SC3`(초안) / 강사 `TC0`(2024 국내) `TC0B`(2025-11-04) `TC1`(2025-11-27) `TC2`(2026-01) `TC3`(2026-08). 누가 어느 판본인지는 아직 모름 → [`contract-version-check.md`](contract-version-check.md)

승인 표시: ◐대화 = 2026-10-16 대화 지시 · ◐기획서 = 2026-10-11 기획서 결정 목록 · ⬜ = 근거만 있고 지시·체크 없음

## 승인하는 방법 (제안)

한 번에 43개가 아니라 **분야별로** 승인하는 것을 추천한다. 순서: ① 변경권 → ② 수강 횟수 → ③ 보강 → ④ 이월 → ⑤ 강사 급여.
각 분야는 "이 표의 `적용 대상` 판본에 대해서만 승인"이며, 다른 판본 학생·강사의 조건은 판본 확인 결과(D-16·D-17)를 본 뒤 따로 정한다.
