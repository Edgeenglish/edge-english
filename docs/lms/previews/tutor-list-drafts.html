휴대폰

지금 화면과 다른 점

  • 칸(카드) → 한 줄. 칸 이름은 Class Record 시트와 같게 (Covered Topics·KST 포함).
  • KST: 강사가 체크를 끄면 KST가 사라짐 (강사마다 기억).
  • Remarks: 목록에는 적힌 줄에만 작은 'Remarks' 표시. 내용은 줄을 눌러 펼치면 보임. 새로 쓸 때는 펼친 칸에서 '+ Remarks'. Late를 고르면 이유 칸이 바로 나옴.
  • 휴대폰은 Covered Topics만 이름 아래 작은 글씨로.
  • Classroom·Class notes 버튼은 줄을 펼쳤을 때만 보임.
  • 맨 위 'To record'(기록할 수업) 묶음은 지금처럼 그대로 둠.
